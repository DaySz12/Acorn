# การทดสอบด้วยมือ (Manual tests)

เช็กลิสต์สำหรับสิ่งที่ unit test ทดสอบอัตโนมัติไม่ได้ (UI จริง, event ของระบบปฏิบัติการ, clipboard จริง และสคริปต์ติดตั้ง)
ช่องสถานะบอกตามจริงว่าทดสอบแล้วหรือยัง: ✅ ผ่าน · ❌ ไม่ผ่าน · ⬜ ยังไม่ได้ทดสอบ

ก่อนทดสอบ แนะนำให้แยกข้อมูลทดสอบออกจาก vault จริง โดยตั้ง `ACORN_DATA_DIR` เป็นโฟลเดอร์ชั่วคราว:

```powershell
$env:ACORN_DATA_DIR = "$env:TEMP\acorn-manual"; .\dist\win-x64\Acorn.exe      # Windows (PowerShell)
```
```bash
ACORN_DATA_DIR=/tmp/acorn-manual open dist/Acorn.app                          # macOS
```

## สิ่งที่ตรวจแล้วระหว่างพัฒนา (Windows 11, build 26300)

ผู้พัฒนาทดสอบสิ่งต่อไปนี้ด้วยสคริปต์ระหว่างสร้างโปรเจกต์ สคริปต์ไม่ได้อยู่ใน repo:

| รายการ | วิธีตรวจ | ผล |
|---|---|---|
| แอปเปิดได้ หน้าต่างชื่อ Acorn และแสดงหน้า "สร้าง vault" | เปิด Debug และ Release build แล้วจับภาพหน้าต่าง | ✅ |
| ระหว่างแอปทำงาน ถือ lock ของ `vault.acorn.lock` และปล่อยเมื่อปิด (exit code 0) | พยายามเปิดไฟล์แบบ exclusive ตอนแอปทำงานและหลังปิด | ✅ |
| เปิด instance ที่สองแล้วไม่ crash | เปิดซ้อน 2 ตัว (ไม่ได้ดูภาพหน้าจอของตัวที่สองด้วยตา) | ✅ บางส่วน |
| กันจับภาพหน้าจอ (ค่าเริ่มต้นเปิด) ได้ภาพดำ | `PrintWindow` | ✅ ตรวจเฉพาะ PrintWindow |
| Photino ไม่พิมพ์ web message ลง stdout | redirect stdout แล้วตรวจ | ✅ |
| Release build ไม่เปิด remote debugging แม้มี `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` | ตั้ง env var แล้วตรวจ port | ✅ |
| ทุกขั้นตอนต่อไปนี้ใน UI จริง: สร้าง vault (รหัสสั้นถูกปฏิเสธ) → recovery key 8 กลุ่ม → ยืนยันผิด/ถูก → เพิ่ม entry, สุ่มรหัส, ฟิลด์ลับ → รายละเอียดและคำสั่ง ssh → reveal แล้วซ่อนเมื่อเลือกรายการอื่น → Ctrl+K โฟกัสช่องค้นหา → ค้นหา → สลับธีม → Settings → ล็อกแล้วไม่มีข้อมูลค้างใน DOM → รหัสผิดได้ข้อความทั่วไป → ปลดล็อกแล้วข้อมูลครบ → recover ด้วย recovery key แล้วได้ key ชุดใหม่ | สคริปต์ผ่าน Chrome DevTools Protocol กับ Debug build | ✅ |
| `setup.bat --no-shortcuts` publish ไปที่ `dist\win-x64` และไม่แตะ `%APPDATA%\Acorn` | รันสคริปต์ | ✅ |
| WebView2 profile (`%LOCALAPPDATA%\Acorn\WebView2`) ไม่มีค่าจาก vault หลังรันทดสอบ UI ครบทุกขั้น | ค้นค่าทดสอบในทุกไฟล์ทั้ง ASCII และ UTF-16 | ✅ |
| ปิดแอปแล้วสร้าง vault ใหม่, lock/unlock และ recover ได้ไฟล์ backup ตามจำนวนการบันทึก | ดูไฟล์ใน data dir หลังทดสอบ UI | ✅ |

## Windows — ต้องทดสอบด้วยมือ

**ล็อกอัตโนมัติ (R6)**
- ⬜ ปลดล็อกแล้วกด **Win+L** → กลับมาแล้วต้องเห็นหน้า Unlock พร้อมข้อความ "ล็อกเพราะหน้าจอคอมพิวเตอร์ถูกล็อก"
- ⬜ ปลดล็อกแล้วสั่ง **Sleep** → ตื่นมาต้องอยู่หน้า Unlock
- ⬜ ปลดล็อกแล้ว **ย่อหน้าต่าง** (ค่าเริ่มต้นเปิด "ล็อกเมื่อย่อหน้าต่าง") → เปิดกลับมาต้องอยู่หน้า Unlock แล้วปิดตัวเลือกนี้ใน Settings แล้วลองย่ออีกครั้ง → ต้องไม่ล็อก
- ⬜ ตั้ง auto-lock = 1 นาที แล้วไม่แตะแอป → ต้องล็อกภายในราว 1 นาที / ถ้าขยับเมาส์คลิกหรือพิมพ์ในแอปเรื่อยๆ ต้องไม่ล็อก

**Clipboard (R5)**
- ⬜ คัดลอก password แล้ววางใน Notepad ได้ถูกต้อง → รอ 30 วินาที → วางอีกครั้งต้องได้ค่าว่าง
- ⬜ คัดลอก password แล้วคัดลอกข้อความอื่นจากแอปอื่นภายใน 30 วินาที → หลัง 30 วินาที ข้อความอื่นนั้นต้องยังอยู่
- ⬜ คัดลอก password แล้วกด **ล็อก** → clipboard ต้องว่างทันที
- ⬜ คัดลอก password แล้ว **ปิดหน้าต่าง** → clipboard ต้องว่าง
- ⬜ เปิด Clipboard History (**Win+V**) → ต้องไม่มี password ที่คัดลอกจาก Acorn (ส่วน host/username ที่ไม่ลับปรากฏได้)
- ⬜ คัดลอก host, username และคำสั่ง SSH → ได้ค่าที่ถูกต้อง และไม่ถูกล้างอัตโนมัติ

**กันจับภาพหน้าจอ (R7)**
- ⬜ Snipping Tool (Win+Shift+S) / PrintScreen → หน้าต่าง Acorn ต้องหายหรือดำ
- ⬜ แชร์หน้าจอใน Teams/Zoom/Meet หรือบันทึกด้วย OBS → ผู้ชมต้องไม่เห็นเนื้อหาของ Acorn
- ⬜ ปิด "กันการจับภาพหน้าจอ" ใน Settings แล้วจับภาพอีกครั้ง → ต้องเห็นหน้าต่าง / เมื่อล็อกแล้ว การกันต้องกลับมาเปิดเอง

**การแสดงรหัส (R7)**
- ⬜ กดปุ่มตาที่ Password → แสดงค่า แล้วซ่อนเองหลังราว 12 วินาที (ตั้งค่าได้)

**Recovery key (R1)**
- ⬜ กด "พิมพ์" ในหน้า recovery key → ในตัวอย่างก่อนพิมพ์ต้องมีเฉพาะ recovery key ไม่มีส่วนอื่นของแอป
- ⬜ Settings → สร้าง recovery key ใหม่ → ยืนยัน → ล็อก → ใช้ key เก่าต้องไม่ผ่าน และ key ใหม่ต้องผ่าน

**เปลี่ยน master password (R8)**
- ⬜ Settings → เปลี่ยน master password (กรอกรหัสเดิมผิดต้องได้ข้อความ "รหัสผ่านปัจจุบันไม่ถูกต้อง") → ได้ recovery key ใหม่ → ล็อก → รหัสเดิมต้องไม่ผ่าน รหัสใหม่ต้องผ่าน และข้อมูลครบ
- ⬜ Settings → อัปเกรด KDF เป็น "แข็งแรงพิเศษ" → ปลดล็อกช้าลงเล็กน้อยแต่ยังใช้รหัสเดิมได้

**Backup และไฟล์ (R2, R3, R4)**
- ⬜ แก้ไขรายการ 3 ครั้ง → ในโฟลเดอร์ `backups` ต้องมีไฟล์ `vault-*.acorn.bak` เพิ่มขึ้น
- ⬜ หน้า "กู้คืนจาก backup" → เลือกไฟล์เก่า → ยืนยัน → แอปล็อก → ปลดล็อกแล้วต้องได้ข้อมูลของเวอร์ชันนั้น
- ⬜ เปิด Acorn สองหน้าต่าง → หน้าต่างที่สองต้องแสดง "Vault กำลังถูกใช้งาน" → ปิดหน้าต่างแรกแล้วกด "ลองใหม่" → ต้องเข้าได้
- ⬜ ปิด Acorn ด้วย Task Manager (End task) ขณะปลดล็อก → เปิดใหม่ต้องเข้าได้ปกติ (lock ค้างไม่บล็อก)
- ⬜ ปิดแอป แล้วสร้างไฟล์ `vault.acorn.tmp` ปลอมในโฟลเดอร์ vault → เปิดแอปต้องเห็นคำเตือนว่าย้ายไฟล์ไปไว้ที่ `backups/unfinished-…` และ vault ยังเปิดได้

**Setup script (หัวข้อ 9)**
- ⬜ `setup.bat` (ไม่ใส่ flag) → มีทางลัด Acorn บน Desktop และใน Start Menu ที่เปิดแอปได้
- ⬜ รัน `setup.bat` ซ้ำ → สำเร็จเหมือนเดิม และ vault เดิมยังอยู่
- ⬜ บนเครื่องที่ไม่มี .NET SDK 10 → ต้องได้ข้อความพร้อมลิงก์ดาวน์โหลด และไม่ติดตั้งอะไรเอง

**อื่นๆ**
- ⬜ Release build: กด F12 หรือคลิกขวาต้องไม่เปิด DevTools และไม่มี context menu
- ⬜ หน้าจอที่ scale 100% / 150% / 200% ต้องอ่านง่ายและไม่ล้น

## macOS — ยังไม่ได้ทดสอบบนเครื่องจริงทั้งหมด

ผู้พัฒนาไม่มีเครื่อง Mac ระหว่างสร้างโปรเจกต์ โค้ดส่วน macOS คอมไพล์ผ่าน แต่**ยังไม่เคยรันจริง**

- ⬜ `./setup.sh` บน Apple Silicon และ Intel → ได้ `dist/Acorn.app` (ad-hoc signed)
- ⬜ เปิด `Acorn.app` ครั้งแรกด้วย คลิกขวา > Open (หรือ `xattr -dr com.apple.quarantine`) → หน้าต่างเปิด และฟอนต์/ธีมแสดงถูกต้อง
- ⬜ vault ถูกสร้างที่ `~/Library/Application Support/Acorn/` โดยไฟล์เป็น `-rw-------` และโฟลเดอร์เป็น `drwx------`
- ⬜ ปลดล็อกแล้วล็อกหน้าจอ (Ctrl+Cmd+Q) → ต้องล็อก
- ⬜ ปลดล็อกแล้วสั่ง Sleep / ปิดฝา → ต้องล็อก
- ⬜ Fast user switching → ต้องล็อก
- ⬜ ถ้าข้อที่แล้วไม่ทำงาน: auto-lock เมื่อไม่ได้ใช้งานยังต้องทำงาน (fallback)
- ⬜ ย่อหน้าต่าง → ล็อก (ถ้าเปิดตัวเลือกไว้)
- ⬜ Cmd+Shift+4 / Cmd+Shift+5 / แชร์หน้าจอใน Zoom → หน้าต่าง Acorn ควรถูกซ่อน (best effort อาจไม่ได้ผลกับบาง API)
- ⬜ คัดลอก password → วางได้ → ถูกล้างหลัง 30 วินาที / ล้างเมื่อล็อก / ล้างเมื่อปิดแอป (Cmd+Q)
- ⬜ Cmd+K เปิดช่องค้นหา
- ⬜ พิมพ์ recovery key ได้ (ถ้า WKWebView ไม่รองรับ `window.print()` ให้จดเอง แล้วบันทึกผลไว้ที่นี่)
- ⬜ เปิด 2 instance (`open -n`) → ตัวที่สองต้องเห็น "Vault กำลังถูกใช้งาน"

## Linux (ไม่บังคับ)

- ⬜ `./setup.sh` บน Ubuntu ที่ติดตั้ง `libwebkit2gtk-4.1` แล้ว → แอปเปิดได้ มีไฟล์ `.desktop`
- ⬜ คัดลอกและล้าง clipboard ทำงานได้ (TextCopy ต้องมี `xsel`/`xclip` หรือ `wl-clipboard`)
- ⬜ auto-lock และล็อกเมื่อย่อหน้าต่างทำงาน (บน Linux ไม่มีการตรวจจับการล็อกจอ)
